# Azure Developer Certification

> **Status, September 2026.** **AZ-204: Developing Solutions for Microsoft Azure retired on
> 31 July 2026**, and so did the *Microsoft Certified: Azure Developer Associate* credential it
> granted, along with its free renewal assessment. A credential already earned stays on your
> transcript and remains valid until its normal expiry — a retired exam does not invalidate it.
>
> The suggested replacement is **AI-200: Developing AI Cloud Solutions on Azure**, leading to
> **Microsoft Certified: Azure AI Cloud Developer Associate**.

For the *interview* rather than the exam, work through the
[Azure interview track](../../Interview/Azure/readme.md) — twelve chapters and nine labs, C# / .NET 10
throughout.

---

## AI-200 — the current exam

**Audience:** back-end developer building AI solutions on Azure. The profile lists Azure SDKs, data
management services, monitoring, messaging/eventing, **vector databases**, **Python**, and
containerised apps on Azure.

| Skill area | Weight |
| --- | --- |
| Develop containerized solutions on Azure | 20–25% |
| Develop AI solutions by using Azure data management services | 25–30% |
| Connect to and consume Azure services | 20–25% |
| Secure, monitor, and troubleshoot Azure solutions | 20–25% |

<details>
<summary>Objectives in full</summary>

**Containerized solutions (20–25%)**

- Build, store, version and manage images with **Azure Container Registry**; build with **ACR Tasks**
- Deploy containers to **App Service**, including environment variables and secrets
- Deploy to **Container Apps** — environment configuration and **revision management**
- Event-driven scaling with **KEDA** in Container Apps
- Deploy and manage apps on **AKS** with manifest files
- Troubleshoot ACA/AKS via logs, events and end-to-end connectivity

**Azure data management services (25–30%)**

- **Cosmos DB for NoSQL** — SDK connections and queries; tune RU consumption with indexing policies
  and consistency levels; store and query **embeddings** for vector similarity search; implement a
  **change feed processor**
- **Azure Database for PostgreSQL** — SDK access, schema and indexing design, compute/memory/storage
  sizing for vector workloads, **pgvector** similarity search and **RAG** with metadata filters,
  connection optimisation
- **Azure Managed Redis** — caching, expiry and invalidation; vector indexing for similarity search

**Connect to and consume Azure services (20–25%)**

- **Service Bus** — queues, topics and subscriptions, **dead-letter handling**
- **Event Grid** — filters, custom events, retries
- **Azure Functions** — serverless APIs, triggers and bindings, configuration and deployment

**Secure, monitor, troubleshoot (20–25%)**

- **Key Vault** — secret storage, rotation and retrieval
- **App Configuration** — storing and retrieving app configuration
- **OpenTelemetry** SDKs for distributed tracing
- **KQL** queries over logs and metrics

</details>

## What changed from AZ-204

| Carried over | Dropped | Added |
| --- | --- | --- |
| Containers (ACR, ACA, AKS), Functions, Cosmos DB, Service Bus, Event Grid, Key Vault, App Configuration, monitoring | **Microsoft identity platform / Entra ID auth**, **App Service web apps** as a topic in its own right, **Blob Storage**, **API Management**, Event Hubs, Queue Storage | Vector search and **RAG**, **PostgreSQL + pgvector**, **Azure Managed Redis**, **OpenTelemetry**, **KQL** |

Roughly half the syllabus survives. The dropped half — identity, App Service, Blob Storage, APIM — is
still squarely what an Azure .NET **interview** asks about, so don't skip it just because the exam
did: chapters [02](../../Interview/Azure/02-identity-and-managed-identity.md),
[03](../../Interview/Azure/03-app-service.md), [06](../../Interview/Azure/06-blob-storage.md) and
[10](../../Interview/Azure/10-api-management.md) cover it.

## AZ-204's final skills measured (archive)

Useful as a study checklist even though the exam is gone — the weights were, as of its last update
(14 January 2026):

| Skill area | Weight |
| --- | --- |
| Develop Azure compute solutions (containers, App Service, Functions) | 25–30% |
| Develop for Azure storage (Cosmos DB, Blob Storage) | 15–20% |
| Implement Azure security (Microsoft identity platform, Entra ID, SAS, Graph, Key Vault, App Configuration, managed identities) | 15–20% |
| Monitor and troubleshoot Azure solutions (Application Insights) | 5–10% |
| Connect to and consume Azure services (API Management, Event Grid, Event Hubs, Service Bus, Queue Storage) | 20–25% |

Local notes from that syllabus: [App Service](az-204/app-service.md) · [Azure Functions](az-204/function.md).
